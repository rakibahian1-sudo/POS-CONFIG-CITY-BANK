How to Host This Dashboard Free on GitHub

2-Minute Setup • No Server Needed • Live Web URL

1

Create a New Repository on GitHub

Log in to github.com, click the + icon at the top right, and select New repository. Name it e.g. pos-config-dashboard and set it to Public (or Private).

2

Upload This File as index.html

Save this dashboard code on your computer as index.html. Inside your GitHub repository, click Add file → Upload files, drag index.html, and click Commit changes.

3

Activate GitHub Pages

Go to your repository's Settings → Pages (on the left sidebar). Under Branch, select main and folder / (root), then click Save.

Done! Within 60 seconds, GitHub will give you a live link like:
https://your-username.github.io/pos-config-dashboard/
You can bookmark this URL on any PC or mobile device and upload your daily Excel files anytime!
